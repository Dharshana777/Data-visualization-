# Data Visualization Project

## Overview
This project demonstrates the use of Python for Data Visualization. A sample student performance dataset is analyzed and transformed into meaningful visual representations to identify trends, patterns, and insights.

## Objective
The main objective of this project is to convert raw data into visual formats that make information easier to understand and interpret.

## Dataset
The dataset contains:
- Student Names
- Marks
- Age
- Study Hours

The dataset is created directly within the Python script.

## Visualizations Created
1. Bar Chart - Student Marks Comparison
2. Line Chart - Marks Trend Analysis
3. Pie Chart - Performance Distribution
4. Histogram - Marks Distribution
5. Scatter Plot - Study Hours vs Marks
6. Box Plot - Outlier Detection

## Technologies Used
- Python
- Pandas
- Matplotlib

## Key Insights
- Students with higher study hours generally achieved better marks.
- Most students scored between 75 and 95 marks.
- Performance distribution can be easily understood through charts.
- Visualizations help identify trends and outliers effectively.

## Conclusion
Data visualization is an important step in data analysis. It helps transform raw data into meaningful insights and supports better decision-making.
